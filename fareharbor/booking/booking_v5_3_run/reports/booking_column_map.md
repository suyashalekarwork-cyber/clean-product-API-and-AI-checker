# Booking notes — column map

Every heading suppliers actually wrote, assigned to a column.

Two numbers per heading, and they mean different things:

- **times** — how often the heading appears
- **suppliers** — how many *different* operators use that wording

A heading used 48 times by one supplier is that operator's boilerplate. One
used 42 times by 17 suppliers is a shared concept. Only the second kind is
evidence for a column.
