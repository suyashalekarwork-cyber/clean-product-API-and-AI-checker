These are the products where the supplier gave the extraction gate nothing to work
with. The rule says: no heading naming a column -> everything stays in about. About
half the run looks like this, so whether the gate holds here matters more than the
defect list does.

CAVEAT: group membership is decided by this script's heading regex, which is
deliberately strict (<=7 words, Title Case or ALL CAPS or ends with ':'). 'No
heading' below means 'none my regex could see', NOT 'none exists'. Spot-checking
group 1 found the model was usually right and the regex was blind -- it caught
'Your Day in the Hunter Valley begins at:' (8 words), the inline 'Cost: $79 per
adult', and 'Accessebility' misspelled by the supplier. Finding those is exactly
why extraction uses a language model rather than a string matcher.
